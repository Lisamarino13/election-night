Read the 2026 bars as partial. Early voting is still open, so 2026 is a running total and every prior cycle is a completed one. The only honest like-for-like here is South Carolina, which publishes a figure per early-voting day in both its live file and its archives — so 2026 can be set against the same day of 2022. Everywhere else, compare the shape, not the height. Only Florida, Iowa, Minnesota, North Carolina and South Carolina have a midterm in the archive at all; the rest can only be set against a presidential cycle, which is a different animal.

Early vote is counted statewide, not per contest — every race on a state's ballot draws from the same ballots, so these totals apply to each race listed.

2020 and 2024 were presidential cycles and 2022 and 2026 are midterms; turnout between the two is not comparable, which is why pace is measured against 2022.
